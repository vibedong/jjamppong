# Harness Router

- Read `.harness/current/status/STATUS_KO.md` first.
- Read `.harness/current/readsets/CURRENT_READ_SET.json` for the current stage read set.
- Treat `.harness/current/source/SOURCE_IDENTITY.json` as the local source identity pointer.
- Use `.harness/current/START_HERE.md` as the installed project start guide.
- Read `.harness/runtime/contracts/PLANNING_STAGE_CONTRACT.md` before responding to product ideas, research requests, file-write requests, implementation requests, or status/read set changes.
- Do not use `.harness/archive/`, `_organized_harness_design/`, `docs/`, `tests/`, or `tools/` as first-turn read sources.
- Do not perform external search, external source inspection, technical feasibility analysis, file writes, status/read set changes, PRD generation, issue creation, or product code creation before the required Harness gate passes.
- Use `.\harness.ps1 doctor` for installed-project validation.
